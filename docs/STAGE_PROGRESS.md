## 0.4.5 生态、创造者、历史与实验

正式观察台选中地块后展开「创造者工具」。画笔可覆盖 1×1 至 7×7，边缘自动裁剪。不可通行地形避开居民、历史居民和聚落。地块资源可分别设为 0–1000。干预会进入命令日志。

在「编年史」选择检查点，可预览到当前状态之间的指定 Tick，并从预览时刻生成独立存档。每个世界保留最近 8 个检查点。重新模拟区间最长 8,640 Tick。分支来源保存在当前浏览器的档案列表中。现有 .mcworld 文件导出的是世界快照。

「平行实验室」可对 1–20 个种子运行成对的生态再生倍率对照。每组最多 3,600 天。结果可导出为逐种子 CSV。

「模组中心」接受本地 JSON 清单。世界存档包含已锁定的清单和规则，恢复时会验证依赖精确版本和内容校验值。当前支持初始生态再生倍率与按地形设定的肥力倍率。示例清单：

```json
{"schemaVersion":1,"id":"fertile-forests","version":"1.0.0","name":"沃野森林","rules":{"biomeFertility":{"forest":160}}}
```

居民按照料、补给、迁移、夜间返家和生产任务的优先分数行动。临时中断后可恢复仍可达的寻食目标。家庭在住所附近储备和使用口粮。迁移需要目标聚落有空置住房与可走通的路线，全家到齐后转移归属。

在聚落卡片展开「建造与生产」，可选地块建造农田、水井、道路和工坊，并为成年人安排采集、建造或加工职业。工坊预扣材料并按队列生产。每周在可达且有供需差的聚落间交换食物和木材。贸易累积往来关系，促进技术传播。文化根据实践技术和贸易往来展示。

2026-11-05 验证。核心 75 项、存储 2 项、正式观察台 Chromium 8 项、离线预览 Chromium 5 项通过。构建与 lint 通过。256² 持续短测及内存采样见 [基准记录](BENCHMARKS.md)。

## 0.4.6 专项续做

- 商队逐 Tick 携带实体货物。路径断开时等待并重新寻路，交易条件变化时带原货返回。收货后才记入往来关系。
- 居民可恢复工地、工坊和伐木目标。工地选择考虑距离与现有分工。住房和粮食不足时，家庭可自主迁往有余粮和空置住房的聚落。
- 编年史可导出 .mchistory，在世界档案导入后创建独立档案，保留该包中的检查点。分支树显示当前浏览器中的档案关系。
- 实验地图对照有共同采样时间轴，批量结果导出仍保留逐种子统计。设置新增暮色主题、旧值迁移和可选事件声音。

## Worker 与发布准备验收

- 正式版可见时推进，标签页隐藏时暂停发起新请求。Worker 分段推进，单段目标 8 ms，单个 Tick 保持原子推进。渲染只接收需要的字段，增量快照追加新编年史和指标。
- 模拟故障后可从最近确认快照重建 Worker，恢复草稿与手动存档分开，草稿恢复使用新档案 ID。
- 正式版增加 PWA 构建产物、离线缓存、键盘跳转和导航状态，新增 CI 工作流及发布手册。
- 已完成六组十二年生态守恒与归档校验、四人分工回归和大图三分钟测试。发布构建三分钟实测与适用范围见基准记录。
