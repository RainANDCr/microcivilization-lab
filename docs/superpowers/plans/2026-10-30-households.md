# Households and generations checkpoint plan

沿用用户已授权的完整规格。直接实施，不重新做产品访谈；环境仍受阻的验收项据实保留。

- [ ] 锁定 0.1.0 与 0.2.0 的已知状态哈希；旧世界不增加新字段、不切换规则。
- [ ] 新引擎 0.3.0 / 世界结构 v2，增加家庭、初始年龄与父母引用；外层 .mcworld 仍为版本 1。
- [ ] 真实完工住宅内，成人形成家庭；儿童成年后可建立独立家庭，父母引用保留。
- [ ] 人口出生受住宅空位、营地口粮、父母生存状态、冷却和确定性随机控制。新成员口粮由仓库转移，照料消耗计入 consumed，禁止凭空生成食物。
- [ ] 年龄按虚拟历法计算，儿童不承担生产工作；高龄影响健康；家庭与成员关系可安全存档恢复。
- [ ] UI 显示实际家庭、年龄结构与人口事件，旧版本明确显示未启用。
- [ ] 单元测试、旧规则回归、存储、核心类型、lint、静态构建与独立审查；记录未通过的完整构建/浏览器检查。
