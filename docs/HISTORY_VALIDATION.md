# 0.4.0 历史居民归档 · 2026-11-01

## 行为与格式

新世界默认 engine 0.4.0 / World v3。每次每日人口更新时，将已逝居民从 `agents` 移入 `deceased`，随后评估家庭和出生。日内刚离世的居民可暂留在 `agents`，但不会继续行动，也不算在世人口。

先人保留 ID、姓名、位置、出生和初始年龄、亲缘、当前家庭、经验、动作原因及背包食物/木材。只清空已无用途的 `path/target/known` 缓存。亲缘、家庭、事件继续引用同一个 ID，分配新 ID 时也检查先人记录，不回收死者 ID。遗留物资保留在先人背包，不凭空消失，也不自动成为可领用仓库。

在世居民最多 2,000；在世与已逝记录合计最多 20,000。达到任一记录边界时停止新增人口，继续运行已有居民。历史仍随完整快照保存，因此有明确容量上限；本版本不提供无限历史或分页数据库。旧引擎保持原先总居民 2,000 的规则，旧世界不会自动转换。

## 阈值回归

测试构造有效的历史世界，而非宣称这些记录来自自然运行百年：原有 2,000 条居民记录，其中两位在世父母、1,998 位已逝先人，并保留祖辈和历史事件引用。满足住房、食物及出生条件后：

| 项目 | 0.3.1 | 0.4.0 |
|---|---:|---:|
| 在世居民 | 2 | 3 |
| 独立先人记录 | 无，留在 agents | 1,998 |
| 总居民记录 | 2,000 | 2,001 |
| 新生儿 ID | 未出生 | 2,001 |

检查保留先人姓名、祖辈引用、家庭成员、原有事件、背包物资；出生仅消耗实际照料所需 6 食物，木材总量不变。归档保存恢复后，双方各继续 240 Tick 的完整状态哈希一致。

另覆盖：家庭创始父母归档后保留关系且不再生育；2,000 位在世居民时禁止出生；20,000 条总记录时禁止出生；拒绝超过总记录预算、活人混入先人记录、重复 ID、缺失祖辈、残留路径缓存以及新字段混入旧格式。

## 旧规则与自然模拟
