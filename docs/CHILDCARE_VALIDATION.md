# 0.3.1 家庭供粮检查 · 2026-11-01

本报告描述 0.3.1 供粮检查；后续 0.4.0 历史归档与三版本对照见 HISTORY_VALIDATION.md，原始 CHILDCARE_RESULTS.json 已附加 0.4.0 结果。

## 变化

0.3.0 的幼儿只依靠营地仓库领取口粮。父母在外携带食物时，孩子可能因仓库耗尽而饿死。0.3.1 增加实际的父母送餐与近处领取：保留父母至少 2 食物，转移至多 2 食物，远处需要走到孩子身边。食物只在背包之间移动，进食时才计入消费。

规则只用于新建的 0.3.1 世界；旧存档保持原引擎，无需清空或迁移数据库。历史居民 2,000 的上限未改变。

## 十年对照

命令：`npm.cmd run test:childcare`。两组均为 rain-river / 64² / 24 人 / continent，10 年（86,400 Tick），无人工干预；逐年检查世界结构与食物守恒。原始结果见 [CHILDCARE_RESULTS.json](CHILDCARE_RESULTS.json)。

| 指标 | 0.3.0 | 0.3.1 |
|---|---:|---:|
| 十年末存活人口 | 66 | 98 |
| 累计出生 | 125 | 128 |
| 儿童死亡 | 83 | 54 |
| 全图、背包及仓库食物总量 | 175,199 | 168,725 |

供粮减少了这个种子中的儿童死亡，但尚未消除饥饿，不能据此认定所有环境的人口平衡已合理。
